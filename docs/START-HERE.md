### Path B: Deploy to GitHub Pages (5 minutes)

#### Step 1: Create GitHub Repository
1. Go to: https://github.com/new
2. Repository name: `markdown-viewer`
3. Visibility: **PUBLIC** ⚠️
4. Click "Create repository"

#### Step 2: Connect & Deploy
```bash
# In Terminal, run these commands:

git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/markdown-viewer.git
git branch -M main
git push -u origin main
./deploy-github-pages.sh
```

#### Step 3: Enable GitHub Pages
1. Go to: `https://github.com/YOUR_USERNAME/markdown-viewer/settings/pages`
2. Set Branch to: `gh-pages`
3. Click Save
4. Wait 2-3 minutes

#### Step 4: Visit Your Site
```
https://YOUR_USERNAME.github.io/markdown-viewer/
```
