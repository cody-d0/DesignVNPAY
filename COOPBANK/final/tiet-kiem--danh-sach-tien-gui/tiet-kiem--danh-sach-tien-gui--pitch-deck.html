3 Filter chip touch target ≥ 44px
🎯 Tác động đến người dùng
Small filter chips → mistouch giữa các chip adjacent. người dùng chọn sai filter → xem data sai.
📐 Nguyên tắc vi phạm
  • Fitts's Law: Minimum 44px for interactive elements on mobile.
🔍 Bằng chứng & Phân tích 📸 1601-danh-sach-tien-gui.png
Từ ảnh: chips cao est. 28px < 44px minimum touch target
📚 2 nguồn · Tham chiếu kỹ thuật →
Nielsen #2 — Match Between System and Real World →
"The design should speak the users' language. Use words, phrases, and concepts familiar to the user."
Fitts's Law →
"The time to acquire a target is a function of the distance to and size of the target."

5 Empty state CTA pattern · Nielsen Norman Group →

📐 Nguyên tắc vi phạm
  • Nielsen #4: trạng thái trống CTA phải nhất quán với design system button patterns.

6 Empty state illustration · Nielsen Norman Group →

📐 Nguyên tắc vi phạm
