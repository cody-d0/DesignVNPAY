UXP-001

OTP flow thiếu countdown timer và resend button

Critical
Hiện trạngOTP flow (artboard 7103) thiếu countdown timer và resend button — vi phạm DDL otp-input-1 spec. Only 6 cells visible, no feedback.
Tác độngHuỷ Voice OTT = account-level action. Failed OTP → can't cancel service → stuck paying. Timer + resend = bắt buộc.
Nguyên tắc vi phạm
  • Nielsen #1: Timer = time-critical status. DDL otp-input-1 mandates canResend + timeLeft.
Đề xuất
  • Countdown: 02:00
  • Resend after 30s
  • Error: red cells + message
  • Auto-focus first cell

UXP-002

Nội dung popup prerequisite (7100) có lỗi copy — câu lặp và thiếu rõ ràng

Critical
Hiện trạngPopup prerequisite (artboard 7100) — câu lặp phrase 'đăng ký nhận thông báo' và nội dung thiếu rõ ràng. Copy error on prerequisite dialog.
Tác độngRepeated phrase in popup = sloppy copywriting. người dùng confused: 'What do I need to do first?' Prerequisite must be crystal clear.
Nguyên tắc vi phạm
  • Nielsen #2: Clear, concise language. No redundancy in critical instructions.
Đề xuất
  • Simplify: 'Để huỷ Voice OTT, bạn cần đăng ký nhận thông báo trước. Nhấn OK để tiếp tục.'
  • One clear instruction per popup

UXP-003

CTA label "Đăng ký" sai ngữ cảnh khi màn hình là chỉnh sửa

Major
Hiện trạngCTA label 'Đăng ký' trên artboard 7105 — nhưng context là chỉnh sửa/huỷ, không phải đăng ký mới. Label mismatch.
Tác động'Đăng ký' khi người dùng muốn huỷ = severe confusion. người dùng hesitates: 'Am I registering something new instead of cancelling?'
Nguyên tắc vi phạm
  • Nielsen #2: CTA label must match người dùng intent. Context: huỷ → 'Xác nhận huỷ' or 'Cập nhật'.
Đề xuất
  • Thay "Đăng ký" bằng "Lưu thay đổi" khi màn hình được mở từ context chỉnh sửa. Hoặc: "Xác nhận" nếu đơn giản hơn.
  • Dùng ngôn ngữ và mô hình tâm lý quen thuộc với người dùng ngân hàng
  • Regression test sau triển khai — đảm bảo không break existing flow

UXP-004

Time-picker fields thiếu error state và placeholder

Major
Hiện trạngTime-picker fields 'Từ'/'Đến' (artboard 7105) — no trạng thái lỗi for invalid range, no placeholder hint for format.
Tác độngEmpty time fields without placeholder → người dùng guesses format. Invalid range → no inline error → server reject.
Nguyên tắc vi phạm
  • Nielsen #5: ngăn chặn invalid input.
  • WCAG 3.3.2: Placeholders/labels for input.
Đề xuất
  • Thêm placeholder "HH:mm" cho cả 2 fields. Thêm inline error: "Giờ bắt đầu phải nhỏ hơn giờ kết thúc" khi Từ ≥ Đến. DDL `text-input-1` spec: `error`...
  • Thêm inline validation realtime — không chờ người dùng submit mới báo lỗi
  • Regression test sau triển khai — đảm bảo không break existing flow

UXP-005

Destructive action (huỷ dịch vụ) thiếu visual distinction — "Đồng ý" không có...

Major
Hiện trạngDestructive action 'Đồng ý' (huỷ dịch vụ, artboard 7102) dùng blue button — giống nhau as non-destructive CTAs. No visual distinction.
Tác độngBlue 'Đồng ý' on cancel-service dialog = no urgency signal. Destructive action should use red/warning color or at minimum secondary styling.
Nguyên tắc vi phạm
  • Nielsen #5: Destructive actions need visual differentiation. Red or warning color for irreversible service cancellation.
Đề xuất
  • 'Đồng ý huỷ' → red/outlined destructive style
  • 'Quay lại' → primary blue (safe default)
  • Clear consequence text: 'Dịch vụ Voice OTT sẽ bị huỷ vĩnh viễn'

UXP-006

"Nghe thử" thiếu play state indicator

Minor
Hiện trạng'Nghe thử' (artboard 7101) — chỉ static play_circle icon, không có play state indicator (playing animation, pause state).
Tác độngngười dùng taps play → no phản hồi trực quan → 'Is it playing? Should I tap again?' No progress indicator.
Nguyên tắc vi phạm
  • Nielsen #1: Play state = system status. Animation/pulse during playback.
Đề xuất
  • Thêm playing state: icon đổi sang pause
  • text đổi sang "Đang phát..." với animated indicator. Stop state khi hoàn thành.

Intro box "Nội dung giới thiệu" lặp lại trên cả 2 màn hình

UXP-008

Empty account section thiếu visual guidance

Minor
Hiện trạngEmpty account section (artboard 7105) chỉ có '+Thêm tài khoản' — thiếu visual guidance khi no accounts added yet.
Tác độngEmpty area with just a link = uninviting. Should hiển thị guidance: 'Chưa có tài khoản nào. Thêm tài khoản để bắt đầu.'
Nguyên tắc vi phạm
  • Nielsen #6: Empty states need guidance content.
Đề xuất
  • Thêm placeholder text: "Chưa có tài khoản nào. Nhấn + để thêm tài khoản nhận đọc loa." Validation: require ≥1 tài khoản trước khi enable CTA.
  • Thêm illustration + message giải thích và CTA để người dùng bắt đầu
  • Differentiate giữa "chưa có data" vs "đang loading" vs "lỗi load"
