UXP-001

OTP bottom sheet (7203) thiếu hoàn toàn "Gửi lại OTP" button và countdown timer

Critical
Hiện trạngOTP bottom sheet (artboard 7203) thiếu hoàn toàn 'Gửi lại OTP' button và countdown timer — vi phạm DDL otp-input-1 spec.
Tác độngVoice OTT settings change requires OTP. No resend → người dùng stuck if OTP not received. No timer → silent expiry → rejection without explanation.
Nguyên tắc vi phạm
  • Nielsen #1: OTP timer = time-critical status. DDL spec mandates canResend + timeLeft.
Đề xuất
  • Countdown: 02:00 visible
  • Resend after 30s cooldown
  • Error: red cells + specific message
  • Auto-focus first cell

UXP-002

Time picker fields "Từ"/"Đến" dùng Calendar icon thay vì Clock icon — semantic...

Major
Hiện trạngTime picker fields 'Từ'/'Đến' dùng Calendar icon thay vì Clock icon — semantic mismatch. Time input showing date icon.
Tác độngCalendar icon on time field = cognitive mismatch. người dùng kỳ vọng date picker, sees time options → confused. Clock icon = universal time symbol.
Nguyên tắc vi phạm
  • Nielsen #2: Icons must match content semantics. Clock ≠ Calendar.
Đề xuất
  • Thay Calendar icon (📅) bằng Clock icon (🕐) cho 2 time-picker fields "Từ"
  • "Đến" trong màn hình 7202

UXP-003

Số tài khoản hiển thị đầy đủ trên cả view (7201) và edit (7202) — không mask PII

Major
Hiện trạngSố tài khoản hiển thị đầy đủ trên cả view (7201: '212312312313') và edit (7202: '12312312313123') — PII không mask.
Tác độngAccount numbers exposed on both view and edit screens. Edit screen = more dangerous: người dùng may screenshot settings for reference → PII leaked.
Nguyên tắc vi phạm
  • Nielsen #5: Default masking. View: '2123***2313'. Edit: masked unless actively editing.
Đề xuất
  • Mask in view: '2123***2313'
  • Mask in edit: reveal only when field focused
  • nhất quán policy across view/edit

UXP-004

Thiếu inline error cho time picker khi "Từ" > "Đến" (invalid range)

Major
Hiện trạngTime picker thiếu inline error khi 'Từ' > 'Đến' (invalid range). No validation for start > end time.
Tác độngngười dùng sets 'Từ: 18:00' and 'Đến: 08:00' → invalid range submitted → server-side error or unexpected behavior.
Nguyên tắc vi phạm
  • Nielsen #5: ngăn chặn invalid time range. Inline error: 'Giờ bắt đầu phải trước giờ kết thúc'.
Đề xuất
  • Thêm trạng thái lỗi dưới time picker: "Thời gian bắt đầu phải nhỏ hơn thời gian kết thúc". Dùng red border + error text pattern
  • Thêm inline validation realtime — không chờ người dùng submit mới báo lỗi
  • Regression test sau triển khai — đảm bảo không break existing flow

UXP-005

Xóa tài khoản khỏi danh sách không có confirmation dialog — destructive action...

Major
Hiện trạngXóa tài khoản khỏi danh sách (icon −) không có xác nhận dialog — destructive action không protected.
Tác độngOne-tap delete on account = irreversible. Accidental tap → account removed from Voice OTT → người dùng phải re-thêm and re-configure.
Nguyên tắc vi phạm
  • Nielsen #5: Destructive actions require xác nhận. 'Xóa TK ***2313 khỏi Voice OTT?'
Đề xuất
  • xác nhận dialog: 'Bạn có chắc muốn xóa TK ***2313?'
  • Primary: 'Giữ lại', Secondary: 'Xóa'
  • Undo option within 5s after delete

UXP-006

"Lưu chỉnh sửa" thiếu loading state sau khi submit — nguy cơ double-submit

Major
Hiện trạng'Lưu chỉnh sửa' thiếu trạng thái tải sau submit — no processing feedback.
Tác độngNo loading → double-tap → potential duplicate API calls. Settings may apply twice or conflict.
Nguyên tắc vi phạm
  • Doherty Threshold: Processing indicator within 400ms.
Đề xuất
  • Sau tap "Lưu chỉnh sửa": button chuyển sang trạng thái tải (spinner + disabled) trong khi OTP bottom sheet loading
  • xác minh implementation trên cả iOS và Android — đảm bảo nhất quán
  • Regression test sau triển khai — đảm bảo không break existing flow

UXP-007

Nút "Đóng" trong success popup (7204) là text-link, thiếu button affordance

Minor
Hiện trạngNút 'Đóng' trong success popup (7204) là text-link — thiếu button tín hiệu tương tác. Looks like regular text.
Tác độngText-link in popup = unclear CTAction. Button style needed for popup dismiss action.
Nguyên tắc vi phạm
  • Nielsen #6: Interactive elements need visible tín hiệu tương tác.
Đề xuất
  • Style "Đóng" dưới dạng outlined button (border + padding) để rõ ràng là tappable element
  • Audit toàn bộ app cho cùng pattern — đảm bảo wording nhất quán
  • Tạo content guideline: bảng từ chuẩn (VD: "Đóng" vs "Hủy" vs "Thoát") cho team

UXP-008

Warning "Lưu ý: KHÔNG để thiế..." không đủ nổi bật

Minor
Hiện trạngWarning 'Lưu ý: KHÔNG để thiết bị ở chế độ im lặng' — text không đủ nổi bật. Critical warning looks like regular body text.
Tác độngDevice on silent = Voice OTT won't work. This warning is functionally critical but visually unremarkable → người dùng miss it.
Nguyên tắc vi phạm
  • Von Restorff: Critical warnings must visually stand out. Yellow/amber background + warning icon.
Đề xuất
  • Thêm icon cảnh báo (⚠️ amber) trước text
  • hoặc dùng warning text color (#D97706 amber) để phân biệt với body text
