SCR-GG-001 Menu tiền gửi tiết kiệm › Danh mục chức năng (`SCR-GG-001`) · menu
3 Error popup actionable
🎯 Tác động đến người dùng
người dùng sees error → 'Đóng' → back to nowhere. No guidance: 'Cần TK loại gì? Tạo ở đâu?' Dead-end error modal.
📐 Nguyên tắc vi phạm
  • Nielsen #9: Error messages must suggest constructive next steps. 'Đóng' alone = no recovery path.
🔍 Bằng chứng & Phân tích 📸 1207-gui-gocfail.png
Từ ảnh 1207: Chỉ "Đóng", thiếu hướng dẫn tạo TK
📚 2 nguồn · Tham chiếu kỹ thuật →
Nielsen #2 — Match Between System and Real World →
"The design should speak the users' language. Use words, phrases, and concepts familiar to the user."
Nielsen #9 — Help Users Recognize, Diagnose, and Recover from Errors →
"Constructively suggest a solution."
UXG-235
