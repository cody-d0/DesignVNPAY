UXP-003

Validation lỗi chỉ hiển thị qua popup "Thông báo"

Major
Hiện trạngValidation error shown via popup 'Thông báo' only — no inline field-level errors. người dùng phải dismiss popup, remember which field was wrong.
Tác độngPopup validation = bad UX. người dùng dismisses popup → forgets which field → tries giống nhau thing. Inline error next to field = immediate fix.

Đề xuất
  • Inline error text below each invalid field
  • Red border on error field
  • Scroll to first error with focus
