# Markdown Viewer — Sample Content

Đây là thư mục chứa nội dung mẫu cho Markdown Viewer.

## Hướng dẫn

Thêm file `.md` vào thư mục này, viewer sẽ tự động hiển thị khi refresh trang.

### Tính năng hỗ trợ

- **Headings** — H1 → H6
- **Tables** — Bảng markdown chuẩn
- **Code blocks** — Syntax highlighting
- **Images** — Lazy loading, gallery scroll
- **Links** — Inter-document navigation

## Ví dụ bảng

| Cột 1 | Cột 2 | Cột 3 |
|-------|-------|-------|
| A     | B     | C     |
| D     | E     | F     |

## Ví dụ code

```python

    print("Xin chào từ Markdown Viewer!")
```
